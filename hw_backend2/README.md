## 1. cars-pagination

Пагинация - это способ просмотра списка элементом по-странично.

Реализовать роут `/cars`, 

### который отдает список машин в виде JSON. Роут должен принимать два параметра:
- `page` - указывает какую страницу
- `limit` - указывает кол-во элементов на странице

Установить значения по умолчанию:
- `page = 1`
- `limit = 10`

### вернет первые 10 машин
```http
GET /cars
```

### вернет машины с 5 по 9
```http
GET /cars?page=2&limit=5
```

Список машин лежит в массиве cars

## 2. cars-id

Реализовать роут `/cars/{id}`, который отдает JSON информацию машины с указанным `id`. Машина должна вытаскивать из массива cars.

Каждая машина имеет следующую структуру:
```json
{
"id": 95,
"name": "Ford Taurus",
"year": "2019"
}
```

Если машины с указанной `id` нет, то вернуть текст `"Not found"` с кодом ответа `404`.

## 2. users-all

Реализовать `/users`, который возвращает HTML страницу со всеми пользователями.

Пользователи хранятся в массиве users.

Каждый пользователь имеет следующую структуру:
```json
{
"id": 1,
"email": "test@test.com",
"first_name": "Aibek",
"last_name": "Bekturov",
"username": "deadly_knight95",
}
```

Пример одного пользователя из списка.
```http
<table>
...
<tr>
<td>deadly_knight95</td>
<td>
<a href="/users/1">Aibek Bekturov</a>
</td>
</tr>
...
</table>
```

## 3. users-id

Реализовать `/users/{id}`, который возвращает HTML страницу указанного пользователя со всеми его полями.

Формат и структуру страницы можете определить сами.

## 4. users-pagination 💎
